# UNISON 1.0.0

Aplicativo de comunicação em tempo real para Windows x64, com interface escura/neon, conversas diretas, grupos, comunidades (Spaces), canais, anexos e chamadas de áudio/vídeo. Esta versão estreia a identidade **UNISON**: mascote com headset, wordmark em caixa alta e accent lilás `#C9A0DC` no lugar do verde anterior.

Esta versão pode ser usada de duas formas:

- **Standalone/local:** backend e banco SQLite embutidos; os dados ficam somente no computador.
- **Multiusuário:** o aplicativo conecta a um servidor UNISON publicado com HTTPS, compartilhando as mesmas contas e conversas.

## Requisitos

- Windows 10 ou Windows 11, x64.
- Não é necessário instalar Node.js, npm ou banco de dados.

## Instalação

1. Baixe `UNISON-Setup-1.0.0.exe`.
2. Execute o instalador e siga o assistente.
3. Abra o UNISON pelo atalho criado na área de trabalho ou no menu Iniciar.

Para usar sem instalar, baixe `UNISON-Portable-1.0.0.exe` e execute diretamente.

## Primeiro uso

- **Modo local (padrão):** crie uma conta normalmente. O banco, os uploads e os logs ficam em `%APPDATA%\UNISON`. Desinstalar o aplicativo **não** apaga essa pasta. Se você já usava a versão Telawork, o UNISON importa automaticamente o banco, os uploads e a configuração de `%APPDATA%\Telawork` na primeira execução enquanto `%APPDATA%\UNISON\data\unison.db` ainda não existir; o accent verde antigo é convertido para `#C9A0DC` pelo migration `002_unison_rebrand.sql`.
- **Modo multiusuário:** publique o backend UNISON com HTTPS e adicione `serverUrl` em `%APPDATA%\UNISON\desktop-config.json`:

```json
{
  "serverUrl": "https://sua-conta.alwaysdata.net"
}
```

Mantenha o campo `jwtSecret` se ele já existir no arquivo. Reinicie o aplicativo depois de salvar. O modo remoto não faz fallback para o banco local: se o servidor estiver indisponível, o aplicativo não abre uma cópia local.

No PowerShell, na pasta onde os arquivos foram baixados:

```powershell

Get-FileHash .\UNISON-Portable-1.0.0.exe -Algorithm SHA256
```

## Aviso do Windows SmartScreen

Os executáveis **não têm assinatura digital Authenticode**. Por isso, o Windows pode exibir uma tela azul de "Aplicativo não reconhecido" ou "O Windows protegeu o computador". Isso é esperado para builds sem certificado de code signing. Confira o SHA-256 antes de executar e só use arquivos obtidos nesta página oficial de releases.

## Limitações conhecidas

- Distribuição somente para Windows x64; Windows 10 foi o ambiente validado, Windows 11 é esperado mas não testado neste build.
- O modo local é isolado por computador; ele não sincroniza dados entre máquinas.
- Chamadas de áudio/vídeo podem exigir TURN para funcionar atrás de NAT restritivo.
- Sem SMTP configurado, emails de verificação/recuperação ficam no log do servidor.
- Não há auto-update nem assinatura de código nesta versão.
